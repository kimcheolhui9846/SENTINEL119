## 팀 운영 요약

- 인원·기한: 2명, 2026-11-20 09:00 KST 제출.
- 구현 우선순위: 텍스트 턴 재생부터 전체 데모를 완성하고, SFT 기준선과 추가 PPO 실험을 진행한다. PPO는 제출 필수는 아니지만 시도할 추가 목표다.
- 환경: NVIDIA Brev, 팀 크레딧 100달러, L40S 우선 검토. Zoro-1 다운로드 허가는 확보했으며 실제 인스턴스·모델 로드는 아직 확인하지 않았다.
- 개발 흐름: 최신 `dev`에서 기능 브랜치를 만들고, `dev`에서 통합·팀원 리뷰를 거친다. `main`에는 전체 반영 범위의 리뷰·검증이 끝난 변경만 병합한다.
- 현재 상태: 문서 작성 단계. 구현·학습·API 연결·3종 실행 로그·발표자료·데모 제출은 아직 완료하지 않았다.

정확한 범위와 일정은 프로젝트 명세를, 공식 제출 조건과 미확정 항목은 제출 체크리스트를 기준으로 한다. 일정·환경·완료 상태가 바뀌면 해당 원문과 이 요약을 함께 갱신한다.

## 공유 문서 작성

팀원이 다음 작업을 수행하는 데 필요한 결정, 인터페이스, 검증 결과와 남은 문제를 기록한다. 팀원 인계가 필요하면 `docs/handoffs/<topic>.md`를 사용하고 기존 명세·운영 문서를 링크한다. 실제 실행 결과와 계획·가정을 구분한다.
