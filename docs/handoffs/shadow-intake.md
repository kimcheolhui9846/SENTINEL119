# 수보 판단과 배차 제안 오프라인 비교

같은 신고 턴과 같은 H1b 응답으로 모델의 최상위 분류, 서울 데모의 기존 판단, 새 하네스의 판단을 비교합니다. 새 하네스는 신고 유형과 배차 제안을 따로 반환합니다. 예를 들어 구급 근거가 충분하고 가용 차량이 없으면 `category`는 `ems`, `proposed_unit`은 `null`입니다. 재생에는 Python 표준 라이브러리만 필요합니다.

저장소 루트에서 실행합니다.

```sh
python -B -m replay_shadow data/demo/shadow-prefixes.jsonl --details
python -B -m unittest discover -s tests
```

`--details`를 사용하면 각 턴의 `category`, 실제 근거 턴 번호와 원문, `proposed_unit`, 보류 사유, 모델·어댑터·정책 버전을 확인할 수 있습니다. 새 정책은 파일이나 차량 상태를 변경하지 않습니다. [판단 함수](../../shadow_harness.py) · [비교 실행기](../../replay_shadow.py)

## 적용 범위

- 모델이 턴별 발화로 제안한 대분류가 검토된 신고자 발화와 일치하고 점수가 데모 기준 0.85 이상이면 해당 유형을 확정합니다. 이 버전의 근거 목록은 합성 구급 요청 두 표현, 화재 요청 한 표현과 후속 발화로 한정됩니다. 처음 보는 요청은 보류합니다.
- 활성 요청 뒤 환자·상황을 정정하거나 의미를 확인할 수 없는 신고자 발화가 들어오면 그 통화의 후속 판단을 수동 검토 대상으로 유지합니다. 이 버전에는 자동 해제 경로가 없습니다. 이미 적용된 출동은 이력으로 보존합니다.
- 차량 자격·장비·가용성은 역할별 자원 공급자가 확인합니다. 정책은 전달받은 적격 후보 순서를 사용합니다. 구급 세부 유형 점수가 없으면 세부 유형만 대기합니다. 필수 대분류 점수가 잘못된 기록은 비교 실행기가 거절합니다.

## 기록 형식과 재현

[예제 JSONL](../../data/demo/shadow-prefixes.jsonl)은 한 줄에 신고 한 건입니다. `call_id`는 전체 파일에서 고유합니다. `split`은 `dev` 또는 `test`, `captured_at`은 첫 발화 묶음의 점수를 수집한 시각입니다. 같은 모델·어댑터·기존 정책 버전끼리 비교합니다.

각 턴에는 화자·원문, 정규화된 대분류 점수, 역할별 적격 차량 ID, 이미 배정한 차량, 기존 판단과 기대 판단이 들어갑니다. `gold_category: null`은 당시 정보로 유형을 확정할 수 없었다는 뜻입니다. `gold_proposed_unit`은 그 시점에 **새로** 제안할 차량입니다. 기존 결과와 기대값은 채점에만 사용합니다. 기존 경로가 이미 배차했다면 두 정책 모두 다음 턴에서 그 배차가 반영된 자원 상태를 봅니다. 전체 통화를 정책별로 따로 운행했을 때의 결과까지 재현하지는 않습니다.

합성 신고 9건의 20턴에서 고유한 발화 묶음 18개를 H1b에 각각 한 번 요청했습니다. 모든 응답의 체크포인트 식별자를 검증하고 점수를 저장했습니다. 기존 결과는 그 점수를 서울 데모 `backend/drill.py` 원본에 재생해 기록했습니다. 원본의 Git 파일 식별자는 예제의 `legacy_policy_blob`에 있습니다. 작성자가 추론 전에 정한 대분류 기대값을, 별도 검토자가 각 시점까지의 발화만 보고 검토해 20턴 모두 같은 값을 얻었습니다.

## 합성 테스트 결과

개발 묶음은 3건 6턴, 테스트 묶음은 6건 14턴입니다. 두 묶음의 전체 통화 내용은 서로 다르지만 같은 발화 묶음 두 개와 정책에 등록된 표현이 양쪽에 등장합니다. 아래 수치는 고정된 사례의 기능 비교입니다.

| 테스트 14턴 | 올바른 확정 | 잘못된 확정 | 확정할 수 있었으나 보류 |
|---|---:|---:|---:|
| H1b 최상위 분류 | 8 | 6 | 0 |
| 기존 관제 판단 | 3 | 1 | 5 |
| 새 하네스 | 7 | 0 | 1 |

대분류 근거가 충분한 8턴 중 새 정책은 7턴을 맞혔습니다. 남은 한 턴은 근거 목록에 없는 구급 요청 표현이었습니다. 실제 신고에서의 일반화 성능과 화면 표시까지의 지연은 별도 평가 대상입니다.
